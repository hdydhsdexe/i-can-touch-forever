# I can touch forever!

《以撒的结合：忏悔+》鼠标拾取 Mod，原名 **Mouse Pickup／鼠标拾取**。无需 REPENTOGON；MCM 和 EID 均为可选依赖。

A mouse pickup mod for The Binding of Isaac: Repentance+, formerly Mouse Pickup. Right-click reachable pickups after clearing a room while your character stays in place. No REPENTOGON required; MCM and EID are optional.

## 安装 / Installation

将仓库中的 `mouse_pickup` 文件夹放入游戏的 `mods` 目录，在 MODS 菜单启用 **I can touch forever!**，然后重新开始一局。入口应为 `mods/mouse_pickup/main.lua`。订阅版与手动安装版只启用一份。

Copy `mouse_pickup` into the game's `mods` directory, enable **I can touch forever!**, and start a new run. Keep only one active copy when also subscribed on Workshop.

正式代码的 `mpickup/development.lua` 应保持 `return false`；不需要打开调试控制台或修改 MouseControl。

## Mod Config Menu 设置（v0.1.8）

启用 MCM 后，在菜单中找到 **I can touch forever!**。所有选项在同一页，使用 MCM 原有的方向键和确认键操作。不需要 MCM 也能运行；已保存的配置在未启用 MCM 时仍然生效。中文版 MCM 与 Pure 应分别使用，不要同时启用两版。

| 设置 | 默认 | 说明 |
|---|---|---|
| 启用鼠标拾取 | 开 | 同时控制远程拾取、领取者切换及本模组悬停显示；普通走动拾取不变 |
| 拾取按键 | 右键 | 可选右键、中键、鼠标键 4／5，不占用左键 |
| 切换领取者按键 | 中键 | 可选相同四键，仅切换当前支持的领取者组 |
| 显示光标 | 开 | 控制 `+` 与魂石领取者的空心菱形 |
| 显示目标选框 | 开 | 控制目标两侧的方括号 |
| 显示状态提示 | 开 | 控制按键、费用及阻挡提示；操作键显示为 `RMB`／`MMB`／`M4`／`M5` |
| EID 悬停联动 | 开 | 关闭后释放本模组接管的说明，不清除其他固定提示 |
| 菜单语言 | 自动 | 中文版提供自动／中文／英文；Pure 固定英文，并保留此前中文语言偏好 |

两个操作选择相同按键时自动交换，一次保存两个绑定。按键以游戏鼠标编号为准；侧键是否产生相应输入取决于鼠标及其驱动映射。隐藏光标、选框或状态不会改变拾取判断，也不会停用 EID。

修改后立即生效并保存到本模组对应的游戏存档槽，重开和续局保留；三个存档槽分别保存。开菜单、关闭总开关或改键会取消未完成的点击并恢复临时移动的物品，已经发生的原生收益不回滚。关闭菜单、重新启用或改键后必须松开相关按键再按；同时按拾取键和切换键时只切换。改变按键不重置当前领取者。

下文中的“右键”和“中键”指默认绑定。

## 使用与规则

- `+` 是鼠标位置；方括号标出这次点击的唯一目标。同色空心菱形只用于下表两类同角色魂石叠加的临时领取者，本体成员保持普通 `+`。
- 绿色 `RMB`：可尝试拾取；黄色：有费用或风险；红色：当前不能点击。
- `BLOCKED`：不存在稳定安全的接触路径；`WAIT`：原生掉落冷却；`NO COINS`：余额不足；`NEEDS BOMB`：需要先炸开。
- `15c` 等数字表示金币价格；`HP COST` 表示生命等交易代价；`DAMAGE` 表示接触伤害；`KEY` 表示需要钥匙。游戏自身决定实际消耗和是否成功。
- 完全重叠时只选择最上层。不能领取的上层不会被跳过；可照常移动角色处理这些情况。
- 一次按下只处理一个目标，长按不连点，开箱不会自动收取全部产物。
- 里蓝人可右键领取普通翔块和大翔块，容量及收益沿用原生碰撞规则。本机原生实测：小翔块增加 1、大翔块增加 3，库存上限为 9；满库存时翔块仍会被消耗，右键也保留此行为。
- 举起合成宝袋时，可装袋材料显示绿色 `BAG`；右键只装入选中的一件掉落物，双份材料、袋满替换和二选一取消其他选项均沿用原版规则。角色保持原位，不自动合成。
- 每次右键触发一次原生挥袋；挥袋结束会收袋，再次装袋前需重新举起。
- 举袋时箱子、道具底座、饰品显示 `NOT MATERIAL`；付费材料或商店库存显示 `SHOP ITEM`。这些目标须收起宝袋后按普通规则处理，不会自动退回普通拾取。点击后若举袋状态改变，本次点击取消。
- 暂停、战斗、切房和 Mod Config Menu 打开时不处理点击；恢复后须松开再按。
- 当前源码扩展单人多实体角色支持，具体规则见下表。普通双子默认由雅各领取；按下鼠标中键切换领取者，白色 `+` 光标表示雅各，红色 `+` 光标表示以扫，不在光标旁显示角色文字。悬停物品或空白处均沿用领取者的光标颜色，物品方括号和状态提示仍按可拾取、费用或阻挡状态着色。中键长按只切换一次，双子选择跨房间保留，新开局重置为雅各。这些改动已随 v0.1.7 发布。
- 右键仅由选定的双子领取；不能领取时不会自动改交另一人。中键切换会取消尚未结算的点击，同时按中键和右键只切换。两人的位置保持原样，血量、槽位、交易及共享资源由原生碰撞结算；通路检查只使用领取者本人的能力。
- 同伴举起宝袋或正在挥袋时显示 `OTHER BAG`，暂不移动目标，避免被同伴装袋；收袋并结束挥袋后恢复。已选领取者举袋时仍执行其本人的装袋操作。
- 形态、领取实体或可用状态变化时取消旧请求；恢复后需松开并重新右键，不自动补领。已发生的原生收益不回滚。当前源码包含下列四种多角色道具单独效果，以及明确列出的一个稻草人或一个魂石叠加组合；多个稻草人、重复魂石、多种效果混用、其他特殊角色叠加、多人及第三方组合继续排除，不以相同控制器作为兼容依据。
- 箱子只执行原版接触行为；石箱需要先炸开。结局大箱子、奖杯、床、传送设施不支持。

| 角色 | 领取规则 | `+` 光标 |
|---|---|---|
| 普通单角色 | 当前角色领取 | 白色 |
| 里雅各两种状态（2026-10-19 用户人工验收通过） | 当前角色领取；暗以扫不是领取者，清房限制保持原样 | 白色 |
| 普通双子 | 中键切换领取者 | 雅各白色，以扫纯红色 |
| 普通遗骸 | 跟随游戏当前身体／灵魂形态，中键不切形态 | 身体灰色 `(0.65, 0.65, 0.65)`，灵魂蓝色 `(0.3, 0.65, 1)` |
| 里遗骸 | 仅身体落地静止时启用，固定由身体领取；抱起、投掷及召回期间禁用 | 灰色 |

| 单独效果 | 领取规则 | `+` 光标 |
|---|---|---|
| 稻草人 | 中键在主角色与一个稻草人之间切换 | 主角色白色，稻草人金色 `(1, 0.8, 0.25)` |

上述单独效果支持普通单角色；特殊角色叠加目前仅限下方列出的一个稻草人或一个魂石组合。成员身份不变时跨房间保留选择；成员生成、死亡、消失或替换后回到基础角色的默认领取者，重开和续局重新建立选择。隐藏形态不进入中键列表，小以扫切换期间取消请求并等待前台稳定。任一其他同组成员举袋或挥袋时阻止远程移动目标。原生拒收、费用、血量、槽位替换及共享资源结算仍由游戏决定。

| 特殊角色＋一个稻草人 | 中键顺序 | 光标 |
|---|---|---|
| 普通双子，任一方持有 | 雅各 → 以扫 → 稻草人 → 雅各 | 白 → 红 → 金 |
| 普通遗骸 | 当前身体／灵魂 → 稻草人 → 当前形态 | 灰／蓝 → 金 |
| 无长子名分的里拉撒路 | 当前前台 → 该前台的稻草人 → 当前前台 | 白 → 金 |

中键不切换遗骸或里拉撒路的原生形态。遗骸隐藏形态参与同组保护；里拉撒路翻到未持有稻草人的另一面时，同伴按原生行为退出当前组。形态或归属变化会取消请求并重置选择；未变化时切房保留选择。稻草人死亡后退出中键列表，普通双子仍可在雅各和以扫之间切换。里拉撒路获得长子名分后，该稻草人叠加组合暂停远程领取。

| 特殊角色＋一个魂石效果 | 中键顺序 | 光标 |
|---|---|---|
| 普通双子＋遗骸魂石，任一方使用 | 雅各 → 以扫 → 临时身体 → 雅各 | 白 → 红 → 灰 |
| 普通双子＋双子魂石，任一方使用 | 雅各 → 原生以扫 → 临时以扫 → 雅各 | 白 → 红 → 红色菱形包围 `+` |
| 普通遗骸＋双子魂石 | 当前身体／灵魂 → 临时以扫 → 当前形态 | 灰／蓝 → 红 |
| 普通遗骸＋遗骸魂石，含长子名分 | 当前身体／灵魂 → 临时身体 → 当前形态 | 灰／蓝 → 灰色菱形包围 `+` |
| 无长子名分里拉撒路＋双子魂石 | 当前前台 → 临时以扫 → 当前前台 | 白 → 红 |
| 无长子名分里拉撒路＋遗骸魂石 | 当前前台 → 临时身体 → 当前前台 | 白 → 灰 |

两种魂石分别使用，不混用。遗骸魂石只选择引擎实际提供的身体，不生成或切换灵魂。普通遗骸原生切形态、里拉撒路翻转时取消旧请求并回到当前基础形态；里拉撒路的魂石同伴随原生关系转到新前台。切房后临时同伴按原生行为消失，旧请求取消，必须松开并重新右键。里拉撒路长子名分叠加仍禁用。

普通双子＋双子魂石、普通遗骸＋遗骸魂石中，空心菱形区分魂石领取者与同色本体成员，不显示角色文字。菱形围绕原有 `+`，沿用同一颜色与透明度 `0.8`；悬停物品或空白处一致，`+` 的位置、大小和点击坐标不变。此前组合保持普通 `+`。两个以扫按原生双子关系、魂石标记及父实体区分；两个身体按本体身体／灵魂关系与魂石父实体区分，不依赖玩家枚举顺序。临时遗骸仅提供实机确认的身体，不访问本体隐藏灵魂。成员、身份、关系或形态变化时取消旧请求并回到雅各／遗骸当前本体形态，必须松开并重新右键。

正常退出后继续游戏，稻草人重新默认选择主角色；两种魂石临时同伴按游戏原生行为消失。小以扫继续跟随保存的前台形态，不会因重建选择而强制切回原身体。

里遗骸使用灵魂的操作状态，但领取位置、通路、能力和库存判断使用身体；不会借用灵魂的飞行能力或搬动身体。这是本模组的保守操作规则，不表示灵魂无法原生拾取。光标透明度仍为 `0.8`。

- 安装 EID 后，鼠标悬停在可描述的掉落物或道具上时，EID 优先显示该目标的信息；移开后恢复原本的显示。无需开启 EID 的鼠标 HUD 功能。重叠时沿用鼠标框选的最上层目标，不穿透到下层。
- EID 联动沿用本模组的清房、角色支持范围和交互状态限制；双子切换时，本模组的障碍隐藏判断跟随领取者。`BLOCKED`、余额不足等不能拾取的目标仍可查看。未安装 EID 时照常运行，没有 EID 描述的目标不接管说明框。
- 本模组不自行生成道具说明；EID 联动遵守其盲道具、未识别药丸、商店及障碍隐藏设置。循环道具的说明随当前内容更新，实际拾取以接触时的内容为准。EID 或其他模组已有的固定提示保留优先权。

当前源码的“可达”同时检查地形通行和已支持的沿途危险，不模拟角色走过路径，也不补扣沿途伤害。第三方自定义拾取物和危险不在保证范围。

## 稳定安全通路规则（已实现，用户人工验收通过）

以下规则已在 v0.1.6 中实现并通过模拟回归。2026-10-21 用户确认本轮完整危险专项人工验收通过；未另提供逐项步骤或日志，不计入自动检查数量。

普通隔空拾取和宝袋装袋统一要求：**目标支持交互，且角色存在一条稳定安全的接触路径。** 允许安全绕路，不模拟角色移动、不补扣沿途伤害，也不假设角色会预先清除障碍。允许尝试不代表必定领取成功。

| 地形或状态 | 规则 |
|---|---|
| 固定地刺 | 非飞行且无对应持续免疫时禁止穿越；飞行或持续有效的对应免疫允许通过。有安全绕路时仍可领取。 |
| 伸缩地刺等周期危险 | 按整个周期判断，不利用短暂关闭领取；永久关闭、移除或具备对应持续免疫后放行。 |
| 火焰、伤害液体、带刺障碍 | 分别检查通行条件和对应伤害免疫；飞行不等于免疫所有危险。非伤害减速地面不单独阻止领取。 |
| 坑洞和实体障碍 | 按当前实际通行能力判断，不预设炸开、破坏、解锁或填坑；房间边界仍然阻挡。 |
| 短暂无敌、受伤闪烁、一次性护盾 | 不作为跨越危险的依据；血量足够承伤也不放行。 |
| 边缘接触 | 允许从安全位置实际接触目标，但角色接触范围与到达路径都不能穿过未豁免的危险。 |
| 点击后的状态变化 | 执行前重新检查地形、危险、能力及举袋状态；条件失效则取消。 |

现有物品支持范围、角色限制、冷却和重叠选择规则继续适用。刺箱等目标自身的接触伤害仍由原版结算；金币、钥匙、生命交易和容量限制同样由游戏决定。宝袋继续遵守材料限制及付费物品禁装规则，并执行相同的安全通路检查。

新规则下，`BLOCKED` 表示不存在符合角色当前能力的稳定安全接触路径；现有费用、伤害与冷却提示保留。具体危险状态、伤害范围和免疫对应关系须经原生实测确认，不能仅凭持有某道具认定安全。第三方自定义拾取物和危险不在本次保证范围。

实现范围：固定／周期地刺、刺石、会再生的红粪堆、火盆实体，以及敌方红／绿／黄伤害液体。地刺免疫识别飞行、老茧、孤儿袜和扁锉；液体免疫识别飞行、老茧和孤儿袜；刺石只按飞行或扁锉豁免危险，仍须满足通行条件。火盆不因飞行放行。其他自定义免疫、动态弹幕、移动陷阱及未列出的效果未纳入保证范围。

实现按角色半径扩张危险区域，检查格子中心之间和边缘接触时的路径；每个逻辑帧更新，执行点击时强制重查。此网格近似可能保守拒绝紧贴危险边缘的狭窄通路，不保证复现所有手动走位。具体状态和范围仍须游戏内验证。

## 打包 / Packaging

在 PowerShell 中运行 `./tools/package.ps1`，生成 `dist/ICanTouchForever-0.1.9.zip`。包内保留 `mouse_pickup` 目录，包含正式代码、资源、中英安装说明及 MIT 许可证。打包脚本要求开发模式关闭。

Run `./tools/package.ps1` in PowerShell to create the manual installation archive. Development mode must remain disabled.
